# Локальное распознавание на Apple Silicon

`transcribe.py` использует MLX Whisper на GPU. Это самостоятельная проверка
распознавания: без planner, TTS, ROS, wake word и команд роботу. Основной
сервер пока использует прежний PyTorch Whisper. Все остальные компоненты
в этой папке ещё не объединены в общий запуск.

Нужны установленный `mlx-whisper` и FFmpeg в окружении `agenticbot`.
Ниже команды для терминала. Сначала активируй окружение и открой папку проекта:

```bash
conda activate agenticbot
cd /Users/satenik/personal_github/AgenticBotIW
```

## Запись микрофона

```bash
python local/transcribe.py --microphone --seconds 10 --language ru
```

Команда записывает 10 секунд звука, распознаёт фразу и создаёт новый
`local/transcript-ДАТА-ВРЕМЯ.txt`. Аудио сохраняется временно и удаляется
после обработки. При первом запросе macOS может попросить доступ
к микрофону для приложения, в котором открыт терминал.

Первая запись может включать задержку запроса разрешения. Для выбора другого
микрофона вывести список устройств:

```bash
python local/transcribe.py --list-microphones
```

Смотри секцию **AVFoundation audio devices**. Индекс можно передать через
`--mic-index 1` (замени `1` нужным индексом). Список идёт в stderr;
FFmpeg может завершить его сообщением об отсутствии входного файла —
при перечислении устройств это ожидаемо, запись не запускается.

## Готовый файл

```bash
python local/transcribe.py --file "/полный/путь/к/записи.m4a" --language ru
```

Следует заменить путь настоящим. Результат появится рядом с аудиофайлом с расширением
`.txt`. Исходное аудио не меняется. Для другого пути результата добавляется
`--output "/полный/путь/к/новому_результату.txt"`. Существующие файлы
не перезаписываются; папка назначения должна существовать.

По умолчанию используется `mlx-community/whisper-medium-mlx`.
`--model` позволяет указать другой совместимый MLX checkpoint или локальную
папку. Первый запуск скачивает отсутствующие файлы модели с Hugging Face
в его стандартный кеш; следующие используют кеш. Распознавание выполняется
локально, аудио кодом скрипта на сервер распознавания не отправляется.

`--language en` — английский, `--language auto` — автоопределение языка.
Время первого распознавания включает загрузку модели, поэтому его нельзя
напрямую сравнивать с последующими запусками.

Справка без загрузки модели и обращения к микрофону:

```bash
python local/transcribe.py --help
```

Исходники: [MLX Whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper),
[модель medium](https://huggingface.co/mlx-community/whisper-medium-mlx).
