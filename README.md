# AgenticBotIW

Учебно-исследовательская система голосового управления SO-101.
Речь преобразуется в проверяемый план из разрешённых навыков;
LLM не управляет суставами напрямую.

## Структура

- `server/` — основной Whisper STT-сервис, планировщик, SQLite,
  Silero TTS, серверные варианты исполнителей и ROS-интеграции.
- `client/` — актуальный голосовой клиент, локальный ROS-мост,
  конфигурация и клиентские варианты робототехнических компонентов.
- `experiments/` — самостоятельные эксперименты с распознаванием речи.
- `whisper.cpp/` — сторонний проект; его использование основным
  Python-контуром не подтверждено.

## Взаимодействие

`client/voice_client.py` → WAV по HTTP → `server/stt_server.py`
→ проверка слова активации → `server_command_pipeline.py`
→ объекты сцены и planner → проверенный TaskPlan → preview/исполнение.

Ответ planner → `server/tts_server.py` → WAV → воспроизведение клиентом.

По умолчанию используются:

| Компонент | Адрес |
| --- | --- |
| STT | `http://127.0.0.1:8000/transcribe` |
| Planner | `http://127.0.0.1:8010/plan` |
| Executor / bridge | `http://127.0.0.1:8020` |
| TTS | `http://127.0.0.1:8030/synthesize` |

Переменные клиента: `STT_SERVER_URL`, `TTS_SERVER_URL`, `ROBOT_BRIDGE_URL`.
Переменные серверной обработки: `PLANNER_URL`, `EXECUTOR_URL`, `AUTO_EXECUTE`.
Одинаковый порт мостов в старой распределённой схеме мог использоваться
на разных машинах. Для запуска обоих на одном Mac нужно отдельно согласовать
топологию и порты; текущий рефакторинг её не меняет.

## Исполнение

Клиент может отправлять готовый preview на локальный `/publish`, когда
сервер возвращает `AUTO_EXECUTE_DISABLED`. Поэтому `AUTO_EXECUTE=0`
само по себе не запрещает публикацию задач во всей системе.
Команда stop на сервере также обращается к исполнителю независимо от этого флага.

Серверный и клиентский варианты ROS-нод, протоколов и конфигураций различаются.
Они сохранены раздельно. Их объединение требует отдельного анализа.

## Проверки

Из папки `server/`: `python3 -B -m unittest discover -s tests -v`.
Команда запускает обычные Python-тесты без аппаратных ROS smoke-тестов.
Нужны совместимое окружение Python, Pydantic 2 и requests.
Не импортируйте экспериментальные скрипты для проверки синтаксиса:
часть из них загружает модели или открывает микрофон при импорте.

Старые `robot_ws/build`, `install`, `log` сохранены как артефакты
предыдущей машины; после переноса их пути могут быть недействительны.
