# Эксперименты с распознаванием речи

Эти программы отделены от основного клиент-серверного контура.

| Скрипт | Назначение |
| --- | --- |
| `transcribe_dataset_sample.py` | Whisper через Transformers на примере из датасета |
| `transcribe_microphone_whisper_mic.py` | Микрофон через WhisperMic |
| `transcribe_microphone_sounddevice.py` | Локальный Whisper и запись через sounddevice |
| `standalone_stt_server.py` | Упрощённый HTTP STT-сервер со словом активации, без planner |

Первые три скрипта были продублированы в прежних `STT/` и `AgenticBotIW/`.
Оставлено по одной копии без изменения содержимого.
`standalone_stt_server.py` перенесён из прежней `STT/stt_server.py`
также без изменения содержимого.

Упрощённый сервер не заменяет `server/stt_server.py`: у него нет
серверной обработки планирования и исполнения. Актуальный голосовой клиент
ожидает ответ с pipeline, который этот экспериментальный сервер не формирует.

Скрипты могут загружать модели, датасеты, обращаться к микрофону
или запускать сервер. Не запускайте и не импортируйте их автоматически.
Использование на Mac ещё не проверено.
